# '/account' Commands
AdminCommands.Account.Description:					    계정을 새로 만들고, 기존 계정을 관리하며, 계정의 캐릭터 배정을 제어합니다.
AdminCommands.Account.Syntax.AccountName:               /account accountname <characterName>
AdminCommands.Account.Usage.AccountName:			    해당 캐릭터와 연결된 계정을 확인합니다. 오프라인 캐릭터에도 사용할 수 있습니다.
AdminCommands.Account.Syntax.ChangePassword:            /account changepassword <accountName> <newPassword>
AdminCommands.Account.Usage.ChangePassword:			    기존 계정의 비밀번호를 변경합니다. 플레이어가 비밀번호 초기화를 요청한 경우 계정 소유권을 확인하세요.
AdminCommands.Account.Syntax.Create:                    /account create <accountName> <password>
AdminCommands.Account.Usage.Create:					    지정한 로그인 정보로 새 계정을 만듭니다.
AdminCommands.Account.Syntax.Delete:                    /account delete <accountName>
AdminCommands.Account.Usage.Delete:					    지정한 계정과 연결된 모든 캐릭터를 함께 삭제합니다.
AdminCommands.Account.Syntax.DeleteChar:                /account deletecharacter <characterName>
AdminCommands.Account.Usage.DeleteChar:				    일치하는 캐릭터를 연결된 계정에서 삭제합니다.
AdminCommands.Account.Syntax.MoveChar:                  /account movecharacter <characterName> <destAccount>
AdminCommands.Account.Usage.MoveChar:				    지정한 캐릭터를 대상 계정의 같은 렐름에서 비어 있는 첫 슬롯으로 이동합니다.
AdminCommands.Account.Syntax.Status:                    /account status <accountName> <status>
AdminCommands.Account.Usage.Status:					    사용자 지정 동작을 정의하는 계정 상태값('0'부터 '255'까지)을 설정합니다.
AdminCommands.Account.Syntax.Unban:                     /account unban <accountName>
AdminCommands.Account.Usage.Unban:					    활성화된 계정 차단 상태를 해제합니다. 이 명령어는 IP 전용 차단('/ban ip')은 해제할 수 없지만, '/ban both'와 '/ban account' 기록은 해제합니다.

# '/plvl' Commands
AdminCommands.Plvl.Description:                         계정의 권한 레벨(plvl)을 변경하고 사용자의 plvl에 따라 명령어 유형 접근 권한을 부여하거나 회수합니다. 이 명령어로 게임 내에서 계정에 Admin, GM, Player 명령어 접근 권한을 부여할 수 있습니다.
AdminCommands.Plvl.Syntax.Comm:                         /plvl command
AdminCommands.Plvl.Usage.Comm:                          '/plvl' 명령어 유형에 대한 추가 정보를 표시합니다.
AdminCommands.Plvl.Syntax.Plvl:                         /plvl <newPlvl> <playerName>
AdminCommands.Plvl.Usage.Plvl:                          대상 플레이어 계정의 권한 레벨을 설정합니다. 이후 해당 역할에 연결된 모든 명령어에 접근할 수 있습니다. Player 상태에서 특정 명령어 유형 접근 권한을 유지하려면 '/plvl single' 또는 '/plvl singleaccount'를 사용하세요.
AdminCommands.Plvl.Syntax.Remove:                       /plvl remove <commandType> <playerName>
AdminCommands.Plvl.Usage.Remove:                        '/plvl single'로 플레이어에게 부여했던 특정 명령어 유형 권한을 제거합니다.
AdminCommands.Plvl.Syntax.AcctRemove:                   /plvl removeaccount <commandType> <playerName>
AdminCommands.Plvl.Usage.AcctRemove:                    '/plvl singleaccount'로 플레이어 계정에 부여했던 특정 명령어 유형 권한을 제거합니다.
AdminCommands.Plvl.Syntax.Single:                       /plvl single <commandType> <playerName>
AdminCommands.Plvl.Usage.Single:                        현재 권한 레벨과 관계없이 캐릭터가 특정 명령어 유형을 사용할 수 있도록 허용합니다. '<commandType>'에는 명령어 식별자만 입력하세요(예: '/player' 명령어는 'player', '/plvl' 명령어는 'plvl' 등).
AdminCommands.Plvl.Syntax.AcctSingle:                      /plvl singleaccount <commandType> <playerName>
AdminCommands.Plvl.Usage.AcctSingle:                       현재 권한 레벨과 관계없이 플레이어 계정의 모든 캐릭터가 특정 명령어 유형을 사용할 수 있도록 허용합니다. '<commandType>'에는 명령어 식별자만 입력하세요(예: '/player' 명령어는 'player', '/plvl' 명령어는 'plvl' 등).
AdminCommands.Plvl.Comm.Intro:                          '/plvl' 명령어 유형으로 계정의 권한 레벨과 해당 계정의 캐릭터가 Player일 때 접근할 수 있는 명령어 유형을 제어할 수 있습니다. 각 plvl에 사용되는 값은 다음과 같습니다:
AdminCommands.Plvl.Comm.1:                              1 = Player
AdminCommands.Plvl.Comm.Usage1:                         몹이나 다른 플레이어에게 공격받을 수 있으며 낙하 피해를 받습니다. Player는 기본 슬래시 명령어('/bg', '/gc', '/cg' 등)만 사용할 수 있습니다.
AdminCommands.Plvl.Comm.2:                              2 = Gamemaster (GM)
AdminCommands.Plvl.Comm.Usage2:                         몹이나 다른 플레이어에게 공격받지 않고 낙하 피해도 받지 않습니다. GM은 대부분의 특수 슬래시 명령어를 사용할 수 있습니다('/plvl', '/account', '/shutdown' 등 ePrivLevel.Admin이 필요한 명령어 제외).
AdminCommands.Plvl.Comm.3:                              3 = Admin
AdminCommands.Plvl.Comm.Usage3:                         몹이나 다른 플레이어에게 공격받지 않고 낙하 피해도 받지 않습니다. Admin은 GM을 포함한 모든 특수 슬래시 명령어를 사용할 수 있습니다.
AdminCommands.Plvl.Comm.UseSingleAcct:                  이 정수들은 게임 내 기능 또는 전투를 테스트하기 위해 권한 레벨('/plvl <newPlvl> <playerName>')을 변경할 때 사용됩니다.
